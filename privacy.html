プライバシーポリシー

AI Voice Hub（以下「本アプリ」）は、作者（milledrian）が自分のためだけに使う、個人用の音声アシスタントです。

使う情報

本アプリは、Google の OAuth で許可を得て、YouTube Data API の読み取りの権限（youtube.readonly）で、次の情報を読みます。

  • 登録チャンネルと、その新しい動画
  • 高く評価した動画
  • 自分のプレイリスト

使い方

これらの情報は、利用者が声で頼んだ動画やプレイリストを探し、利用者自身の端末で流すためだけに使います。 動画への評価・コメント・登録の変更など、YouTube の情報を変える操作はしません。

保存と共有

  • ログインの情報（更新用のトークン）は、利用者自身の PC の中にだけ保存します。
  • YouTube から読んだ情報は保存せず、第三者に提供・販売しません。広告にも使いません。
  • 頼まれた内容に答えるため、読んだ動画の題名などを、回答を作る AI に渡すことがあります。

Google API Services User Data Policy

本アプリによる Google API から受け取った情報の利用と移転は、 Google API Services User Data Policy （Limited Use の要件を含む）に従います。

許可の取り消し

本アプリへの許可は、Google アカウントのサードパーティ アクセスから、いつでも取り消せます。
